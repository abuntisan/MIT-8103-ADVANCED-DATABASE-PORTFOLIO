# Portfolio 2: Query Processing and Optimisation

## 1. Project Overview

This portfolio investigates SQL query processing and optimisation using the FinCore Payments simulated fintech payment processing platform.

The objective is to retrieve payment information efficiently, examine query execution plans, and evaluate how database indexes can affect query performance.

## 2. Objectives

- Write SQL queries for payment transaction analysis.
- Retrieve approved and declined transaction records.
- Analyse transaction volumes and response codes.
- Examine query execution plans.
- Implement suitable database indexes.
- Compare query performance before and after optimisation.
- Document the results and explain the findings.

## 3. Selected Case Study

FinCore Payments is a fictional payment processing platform that stores customers, merchants, payment terminals, payment transactions and transaction reversals.

This portfolio will use the database designed in Portfolio 1.

## 4. Planned Deliverables

- SQL query scripts
- Query result evidence
- Query execution plans
- Index creation scripts
- Before-and-after performance comparisons
- Performance analysis and conclusions
- Screenshots of practical implementation
