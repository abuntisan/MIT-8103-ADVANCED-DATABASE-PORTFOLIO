## Project Overview

This repository contains the practical portfolio for MIT 8103 Advanced Database Systems.

The project uses a simulated fintech payment processing platform called **FinCore Payments** to demonstrate database design, SQL query optimisation, transaction management, NoSQL data modelling, and distributed database concepts.

## Case Study

Fincore Payments is a simulated payment processing system that records payment transactions between customers and merchants. It supports transaction monitoring, response-code analysis, reporting, and reversal tracking.

All project data will be fictional and created for academic purposes.

2. Portfolio 2 — Query Processing and Optimisation
3. Portfolio 3 — Transactions and Concurrency
4. Portfolio 4 — NoSQL and Advanced Data Models
5. Portfolio 5 — Distributed and Cloud Database Exercise
